Wofür wird die Anwendung genutzt?

F.R.I.D.A.Y ist ein privater Assistent, den ausschliesslich der Verantwortliche für sein eigenes Google-Konto nutzt. Es gibt keine weiteren Nutzerinnen oder Nutzer.

Welche Google-Daten werden verwendet?

Mit ausdrücklicher Zustimmung des Verantwortlichen greift die Anwendung auf E-Mails und Kalender des eigenen Google-Kontos zu. Die Daten dienen nur dazu, dem Verantwortlichen Zusammenfassungen, Erinnerungen und Terminvorschläge zu zeigen und von ihm bestätigte Aktionen (z. B. Termine eintragen) auszuführen.

Wo und wie werden die Daten verarbeitet?

Die Verarbeitung läuft auf einem eigenen, privaten Server des Verantwortlichen. Zur Zusammenfassung und Auswertung von Inhalten werden einzelne Texte an den KI-Dienst Claude von Anthropic übermittelt. Eine Weitergabe an weitere Dritte, Werbung, Verkauf von Daten oder Training eigener Modelle findet nicht statt. Die Nutzung von Informationen aus Google-Diensten entspricht der Google API Services User Data Policy, einschliesslich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Speicherung und Löschung

Zugangsschlüssel (Tokens) werden nur auf dem privaten Server gespeichert. Der Zugriff kann jederzeit unter myaccount.google.com/permissions entzogen werden. Gespeicherte Daten werden auf Wunsch gelöscht.
